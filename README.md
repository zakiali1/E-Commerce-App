# ShopEasy E-Commerce App

A Flutter-based e-commerce application designed for browsing products, managing a cart, saving favourites, and completing purchases in a clean mobile shopping experience.

## Features

- Product browsing with category-based navigation
- Search and discovery experience for products
- Wishlist management using app state providers
- Shopping cart and checkout flow
- User authentication screens for login and signup
- Order history and profile management
- Responsive Material Design UI

## Tech Stack

- Flutter
- Dart
- Provider for state management
- SharedPreferences for local persistence
- HTTP for API interaction

## Project Structure

```text
lib/
├── api/

├── widgets/
├── main.dart
```

## Getting Started

### Prerequisites

- Flutter SDK (3.9.0 or later)
- Android Studio / VS Code with Flutter extensions
- An Android emulator or physical device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/zakiali1/E-Commerce-App.git
cd E-Commerce-App
```

2. Install dependencies:

```bash
flutter pub get
```

3. Run the application:

```bash
flutter run
```
